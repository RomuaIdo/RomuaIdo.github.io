## Symptom

The programmer enumerated on USB, but failed to program some microcontrollers. Measuring the board's 3.3 V rail, the output was at **2.3 V**.

This rail does not power only the ST-Link's own logic: the high level of the programming signals comes from it. At 2.3 V, the high level was below the input threshold of some targets, and communication failed.

## Diagnosis

With the USB 5 V input normal and the regulator output low, suspicion fell on the LDO itself, which converts the USB 5 V into the board's 3.3 V.

| | Original | Replacement |
|---|---|---|
| Marking | `LB2K` | `DE-TOX` |
| Component | XC6219B332MR (Torex Semiconductor or Chinese equivalent) | RT9193-33GB (Richtek) |
| Nominal output | 3.3 V | 3.3 V |
| Package | SOT-23-5 | SOT-23-5 |

<Figure src={board} alt="ST-Link V2 clone board on a cutting mat, with the LDO regulator highlighted" caption="ST-Link board with the LDO highlighted." />

## Repair

The original regulator was removed and replaced with the RT9193-33GB, with the same package and output voltage.

## Result

After the swap, the rail returned to a **stable 3.3 V** and the programmer began programming normally the microcontrollers that had failed before.
